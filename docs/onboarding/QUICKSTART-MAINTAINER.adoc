= scaffoldia — Quick Start for Platform Maintainers
:toc:
:toclevels: 2

== Overview

This guide covers building and packaging scaffoldia. scaffoldia is currently
a library (the design-phase RSR substrate plus a typed ABI/FFI seam), not a
standalone executable — see `.machine_readable/descriptiles/STATE.a2ml` for
the honest current state.

== Build-Time Dependencies

* Idris2 0.7.0+ (typed ABI seam, `abi.ipkg`)
* Zig 0.16+ (FFI implementation, `src/interface/ffi/`)
* `just` (task runner)

== Build from Source

[source,bash]
----
git clone https://github.com/hyperpolymath/scaffoldia.git
cd scaffoldia
just build-release
----

Output: `src/interface/ffi/zig-out/lib/libscaffoldia.a`

== Packaging

=== Guix

[source,bash]
----
guix build -f guix.scm
----

=== Nix

[source,bash]
----
nix build
----

=== Manual Package

[source,bash]
----
just install prefix=/usr/local
----

Files installed:

[cols="1,2"]
|===
| Path | Contents

| `$PREFIX/lib/libscaffoldia.a`
| Static library (Zig, `-Doptimize=ReleaseFast`)
|===

NOTE: There is no packaged executable, config file, `.desktop` entry, or man
page yet — scaffoldia is a library in its design phase. This section will
grow once the composition engine ships.

== Health Checks

[source,bash]
----
just doctor            # Full diagnostic (tool checks, hardcoded-path scan)
just build              # Confirms the Idris2 ABI + Zig FFI both compile
just test               # Confirms the Idris2 ABI typechecks + Zig tests pass
----

== Updating

[source,bash]
----
git pull
just build-release
just install prefix=/usr/local
----
