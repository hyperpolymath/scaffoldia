  local Linux runner with Idris2 0.8.0 and Zig 0.16.0.

  and comment-filtered lexical checks.
* `bash tests/workflows/aspect_scope_test.sh`: silence, two firing,
  NOT_RUN controls passed.
* Proven Lock Gate at published pinned source: exit 0, `consistent`;
  remote owner drift and moved repository references were unjudged.

These are not claims about PR CI. Every proposed workflow check must run
and pass on the latest head before promotion. Composer functionality,
proofs, property tests, fuzzing, mutation, rollback and benchmarks remain
gaps, not implicit N/A.
