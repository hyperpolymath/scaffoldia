== Theory claims: ADR-0003 plan laws

The algebra of plan composition and application that ADR-0003 ("Composition is
a join, not an overwrite") lists. Theory obligations (PROOF-POLICY §1): Agda is
the source, rechecked in Rocq and Lean (§2).

* *Sources*: `verification/proofs/agda/PlanLaws/` (graded root `All.agda`;
  one module-level comment per file says what it proves).
* *Invocation*: `cd verification/proofs/agda && agda --safe --without-K
  --cubical-compatible PlanLaws/All.agda` (§2.1), run by `just
  proof-check-plan-laws` (`scripts/check-plan-laws.sh`). The gate also refuses
  any other pragma, a hole, a warning, a postulate in the cone, a prover
  postulate outside the trusted base, and a file outside the cone. Negative
  controls: `just proof-check-plan-laws-controls` (`tests/reject/PlanLaws/Controls/`,
  §8.5.4), each refused for its stated reason.
* *Checker*: Agda 2.7.0.1, the upstream release binary (see the deviation
  below). Ran 2026-11-17 in an agent session, not in CI.
* *Library cone*: none. No agda-stdlib and no `.agda-lib`; the import cone of
  `PlanLaws/All.agda` (`--dependency-graph`) is the nine `PlanLaws` modules and
  `Agda.Primitive`. Postulates in the first-party cone: 0. Trusted base (§8.4):
  the four prover postulates of `Agda.Primitive`, `Level` (`BUILTIN LEVEL`),
  `lzero` (`LEVELZERO`), `lsuc` (`LEVELSUC`), `_⊔_` (`LEVELMAX`).
* *Equality*: plans by `≈` (lookup agrees at every path); outcomes by `~` (any
  two conflicts are related, `ok r ~ ok s` iff `r ≈ s`); file systems by `≗`
  (pointwise). No function extensionality is used or assumed.
* *Model*: paths and contents abstract with decidable equality; a desired state
  is a file with content or absent; a plan is read through `lookup`; `p ⊔ q`
  returns `conflict x` or `ok (p ∪ q)`; `apply` overrides a total file system.
  Preconditions (`expect`) are outside the algebra and return in
  `PlanLaws/Kernel.agda`. An authorised replacement (issue #70) is out of scope.
* *PWG*: `ungraded` for every row. §8.2 grants `PWG-3` only with a receipt that
  records the Agda version, library pin, flags and import cone, and §8.4 derives
  a grade from receipts, never asserts it. No receipt exists yet: the run above
  was on a commit that is not on `main`. What is missing is a proof receipt
  (§8.5.1, `verification/receipts/*_praxis.deed`) for the commit as it lands on
  `main`; with it the reader would derive `PWG-3`. `PWG-3` would still owe both
  recheck legs (§8.4, rule 1).
* *Recheck legs*: Rocq and Lean both `open`, not attempted (route: Dedukti
  transport first, hand re-proof as fallback, no Mathlib; §2).

ADR-0003 law 2 ("a join of safe plans is safe") holds for per-path safety
(PL-15) and is false for the plan-level conditions of plan format v0.1 (no
case-fold collision, no directory-prefix clash): PL-16 gives the exact
condition and PL-17 the counterexample. A kernel must re-check those
conditions on the composed plan.

*Deviation* (PROOF-POLICY §6), state `open`: the leg above is the Agda leg; the
tool is Agda 2.7.0.1, installed from the upstream release archive
`Agda-v2.7.0.1-linux.tar.xz` (SHA-256
`975b515a14877ab6bce5bfc641e16c4a3ee52ca5d7f846577dee80aa2145db8a`; binary
`bin/agda` SHA-256
`6de41437c14c05c9fe576d724cc67386444c0fa9fee662a08250fefb91bee8b6`), not through
Guix or the container, because the session had no Guix and `build/guix.scm`
does not provide Agda. `scripts/check-plan-laws.sh` asserts the version and
fails on a mismatch. It closes when Agda comes from the repository's Guix
manifest or container and a CI lane runs `just proof-check-plan-laws`; no CI
lane runs it today.

*Rust kernel*: the refinement from `PlanLaws/Kernel.agda` to kernel code is an
engineering obligation for Creusot (contracts in Pearlite) and Verus
(PROOF-POLICY §1.2). Status `open` for both: no kernel code exists.
