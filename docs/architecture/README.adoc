= Scaffoldia Architecture
:toc:

== Current implementation boundary

Scaffoldia is a repository design and retrofit project in the design phase.
The repository presently supplies governance metadata, workflow automation
and independently buildable Idris2 and Zig modules. The actual composer,
repository mint operation, retrofit planner and linked ABI are not yet
implemented or qualified.

== Existing directory layout

* `src/` contains source pillars and a generic inherited foreign-function
  interface scaffold; it does not contain a functioning composition engine.
* `tests/` contains existing compiler, Zig and source-scope test harnesses.
* `docs/architecture/` contains this introduction, the component topology,
  and the source threat model.
* `.machine_readable/` holds repository machine metadata, some of which
  is obsolete A2ML awaiting controlled migration to DEED.
* `.github/workflows/` contains automation whose individual checks
  must run and report their true state.
