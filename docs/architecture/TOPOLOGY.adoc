== Ownership boundaries

[cols="1,2,3",options="header"]
|===
| Layer | Repository | Authority / output

| Canon | `metadatastician/standards` | RSR criteria, format rules, template-capability-gates.toml, scaffold lifecycle
| Spine | `hyperpolymath/rsr-template-repo` | `repo-init`, pinned base tree, `archetypes/<name>/<name>_praxis.deed`, overlays, lock fragments, deed clauses
| Composer | `hyperpolymath/scaffoldia` | Future deterministic composition, dry-run mint and retrofit plans, apply and reconciliation receipts
| Oracle | `hyperpolymath/hypatia` | Conformance scoring; Scaffoldia must not redefine scoring
| Sustain | `hyperpolymath/gitbot-fleet` and `hyperpolymath/reposystem` | Audit-first corrective campaigns and owner-gated application
|===

The normative lifecycle is `metadatastician/standards/0-canon/rsr/SCAFFOLD-LIFECYCLE.adoc`
and the spine's accepted ADR-0002/0003. The upstream ADRs were amended
2026-10-06: standalone `VARIANT.a2ml` and `ARCHETYPE.a2ml` files are
superseded by `*_chora.deed` clauses and archetype `*_praxis.deed`.
Scaffoldia consumes these schemas; it does not fork their definitions.

The `developer-ecosystem/scaffoldia` historical Haskell CLI + Nickel
builder is dormant, not an alternate implementation authority. Its CLI
`init` and `build` paths do not invoke the actual composer; the registry
is suitable for reviewed harvesting only.

== Required operational seams (proposed)

[source,text]
----
Canon (version + gates) ------.
Spine (pin + deeds + overlays) +--> validated SourceSnapshot
Identity + capability request -'            |
                                         CompositionPlan
                                     / deterministic / dry-run
                                    /                      \
                             Mint adapter            Retrofit adapter
                                    \                      /
                              Reconciliation/ExecutionReceipt
                                          |
                      provenance + Hypatia + fleet proposal
----

* Ingest: pinned canon/spine snapshots, exact deed contracts and overlays;
  reject unknown capability, unpinned inputs and invalid paths.
* Plan: deterministic ordering; detect duplicate and overlapping path claims;
  emit explicit conflicts; never silent last-writer-wins.
* Apply: sandboxed file staging, no remote mutation by default; authorisation
  required for real repository modification and all forge configuration.
* Reconcile: compare pinned base, current child, and desired child; preserve
  unrelated user edits; report conflicts rather than overwrite.
* Observe: test/build/hypatia/drift evidence and outcome receipts. A skipped
  or absent check cannot be reported as passing.

These are interfaces to implement, not capabilities claimed present.

== ABI/FFI blocker

`src/interface/Abi/Foreign.idr` imports C symbols `rsr_init`,
`rsr_free`, `rsr_process`; Zig exports `scaffoldia_init`,
`scaffoldia_free`, `scaffoldia_process`. Their result semantics differ.
The Idris2 platform model is a simplified 64-bit template, including
inapplicable generalisations. The Zig integration tests import Zig directly;
they do not link Idris2 calls through the C ABI. The interface is therefore
not verified and must not be called 'proven' before an end-to-end link test.
ADR-0002 leaves retention/retirement of this optional seam open.

== Existing CI debt (observed on base commit)

* Well-known enforcement ignores existing `www/.well-known/security.txt`.
* Workflow linter's first-line SPDX check rejects managed lockfile headers,
  then its literal SHA-only rule conflicts with actions.lock's tag-to-SHA map.
* Static analysis gate produced startup_failure; investigate workflow
  permissions, allowlist and pinned reusable workflows separately.
* Some reusables still refer to `hyperpolymath/standards` while the live
  canon is `metadatastician/standards`.
* The `e2e.yml` job invokes a script requiring Idris2 and Zig without
  explicit toolchain provisioning.

Do not suppress failures to create a green summary. Fix at the owning layer
and verify the first real passing and deliberately failing checks.
