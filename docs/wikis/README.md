# Scaffoldia wiki sources

This directory is the repository's human-facing wiki area. Its current
document format is Markdown, consistent with the estate wiki policy;
long-form non-wiki technical documentation remains under docs/ in AsciiDoc.

## Scope

Future wiki material may explain core repository design concepts, operator
workflows, and the glossary for composition and retrofit. These are not
implemented user operations yet; see
[the architecture overview](../architecture/README.adoc) for the current state.

## Synchronisation

No wiki synchronisation run or published wiki is verified by this document.
Do not assume that edits here have reached GitHub, GitLab or any external forge.

The earlier A2ML wiki-track specimen has been preserved in
[the legacy records](../legacy/wikis/0.2-AI-MANIFEST.a2ml).
It required AsciiDoc within a wiki and predates the current wiki-format policy;
it is historical input, not an active standards contract.
